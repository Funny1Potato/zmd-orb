# 终末地加速球 · zmd-orb

一个《明日方舟：终末地》协议核心电量面板风格的桌面小球：**一键整理内存缓存**，同时能当任务管理器用。

适用于 Windows 10 / 11（x64）。界面中文。安装包自带运行时，**不需要另外装 .NET**。

## 怎么用

装好后桌面上有一个悬浮球（也可以改成只在托盘显示）：

| 操作 | 作用 |
|---|---|
| **单击** | 轻度整理（不需要管理员、不弹 UAC，一两秒完成） |
| **拖拽** | 移动位置（位置会被记住，下次启动还在原地） |
| **双击** | 打开面板（任务管理器 + 整理 + 设置） |
| **右键** | 菜单：打开面板 / 轻度整理 / 轻量模式 / 切到托盘模式 / 退出 |

**托盘模式**：不占桌面，托盘图标本身就是内存占用率（圆环 + 数字）。托盘图标的右键菜单与球上的一致。
两种形态与"轻量模式"在三处都能切：球的右键菜单、托盘右键菜单、面板的"显示设置"。

再启动一次 exe 不会出现第二个球，而是直接把已有实例的面板打开。

## 整理内存是怎么回事

Windows 上没有"释放内存"的魔法。这类工具做的是两件事：把冷进程的工作集换出去、把待命列表
（文件缓存）清空。被换出的页在下次访问时要**从磁盘读回来**，所以它不产生内存，只是把内存从
"占用"搬到"可用"，代价是那些页下次访问会变慢。因此本工具的文案写的是"换出 X GB 工作集 /
整理 X GB 缓存页"，不写"释放内存"。

三档整理（面板"整理"那一页）：

| 档 | 做什么 | 需要管理员 |
|---|---|---|
| **轻度** | 整理当前用户进程的工作集 | 不需要 |
| **深度** | 轻度 + 刷已修改页 + 清待命列表 | 需要（弹一次 UAC） |
| **全部** | 深度 + 全系统清工作集 + 清系统文件缓存 | 需要（弹一次 UAC） |

面板上还有**硬缺页率**：那正是整理的代价，每次整理完会给出前后对比。
**自动整理默认关闭**（它只做轻度档，值不值得由你自己判断），阈值与间隔可改。

**不想被整理的进程**写进排除名单 `%LOCALAPPDATA%\zmd-orb\exclude.txt`（每行一个进程名，
`#` 开头是注释，`!名字` 表示从默认名单里去掉）。默认不会动本工具自己、关键系统进程，
也不整理你当前正在用的前台进程。

## 轻量模式

打开后球面更素净、静止时不再持续重画，常驻的内存与 CPU 都明显下降。适合"平时只是看一眼占用率"的
用法。**切换它会让程序重启一次**（这项省下的内存需要换一种绘制方式，只能在启动时确定）。

## 面板里有什么

- **综合占用**：CPU 与内存按权重合成的百分比（权重、以及"100% 对应多少 MB"都能在设置里改）
- **六张读数卡**：已占用内存 / 已提交 / 空闲+零页 / 待命列表 / 已修改 / 硬缺页率
  （"已占用"与"已提交"口径不同：前者含与其他程序共享的页，后者是记在该进程名下的私有提交量，
  所以会出现"已提交比已占用小"，这是正常的）
- **应用概况 / 应用内存**：按 CPU 或内存排序的程序列表（不含"已压缩内存"，它是系统压缩池本身）
- **设备性能**：显卡、磁盘、网络
- **整理与系统信息**：三档整理、自动整理状态与"上次判断"、机器与系统规格

## 显示设置

综合占用的分母与权重、面板刷新间隔、应用概况条数、自动整理阈值与间隔、开机自启、托盘模式、轻量模式。
**这一整张表单都是点「保存」才生效**；「恢复默认」只把表单填成出厂值，同样要点「保存」。

## 命令行

脚本、计划任务、安装包都可以这样调：

```
zmd-orb.exe                        启动（形态按上次记的走）
zmd-orb.exe --mode tray|ball       强制某一种形态
zmd-orb.exe --lite on|off          改轻量模式（只写设置，正在运行的实例要重启才读）
zmd-orb.exe --swrender auto|on|off 改绘制方式（默认 auto：普通模式硬件、轻量模式软件）
zmd-orb.exe --autostart on|off     改开机自启
```

## 文件位置

| 内容 | 位置 |
|---|---|
| 设置 | `%LOCALAPPDATA%\zmd-orb\ui.json` |
| 自动整理参数 | `%LOCALAPPDATA%\zmd-orb\auto.json` |
| 排除名单 | `%LOCALAPPDATA%\zmd-orb\exclude.txt`（也可放在程序同目录） |
| 日志 | `%TEMP%\zmd_orb_shell.log` |

程序常驻**不需要管理员**；只有深度/全部整理时会弹一次 UAC。退出用右键菜单或面板上的「退出」。
卸载用安装目录里的 `uninstall.exe`（或系统"应用和功能"）。
